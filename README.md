# 🤖 1C AI Code Reviewer

Локальный ИИ-ревьюер для кода 1С. Анализирует код через **DeepSeek Coder** (Ollama), формирует отчёт и отправляет его на **почту**. Полностью автономен — работает без интернета в Docker-контейнере.

---

## 🚀 Как запустить

1. **Установите Docker** (Docker Desktop для Windows/Mac или Docker Engine для Linux).

2. **Создайте файл `.env`** в папке проекта и добавьте туда пароль от почты:

   ```env
   EMAIL_PASSWORD=ваш_пароль_приложения
   ```

   Пароль приложения Yandex/Gmail можно создать в настройках безопасности почты.

3. **Соберите Docker-образ:**

   ```bash
   docker build -t my-reviewer .
   ```

4. **Запустите контейнер:**

   ```bash
   docker run --rm --env-file .env my-reviewer
   ```

---

## 🛠 Технологии

- **Python 3** — основной язык скрипта.
- **Ollama** — локальный сервер для запуска LLM.
- **DeepSeek Coder 1.3B** — модель, анализирующая код.
- **Docker** — упаковка и изоляция окружения.
- **SMTP** — отправка отчёта на почту.

## 🔗 Интеграция с 1С

В файле `integration_1c.bsl` находится функция на языке 1С, которая отправляет код на проверку в контейнер и получает ответ.

```bsl
Функция ОтправитьКодНаРевью(ТекстКода) Экспорт

    // 1. Формируем JSON для отправки
    ЗапросJSON = Новый Структура;
    ЗапросJSON.Вставить("model", "deepseek-coder:1.3b");
    ЗапросJSON.Вставить("prompt", "Ты эксперт по 1С. Проанализируй этот код и найди все проблемы:" + Символы.ПС + ТекстКода);
    ЗапросJSON.Вставить("stream", Ложь);

    ЗаписьJSON = Новый ЗаписьJSON;
    ЗаписьJSON.УстановитьСтроку();
    ЗаписатьJSON(ЗаписьJSON, ЗапросJSON);
    ТелоЗапроса = ЗаписьJSON.Закрыть();

    // 2. Подключаемся к Ollama (Docker слушает localhost:11434)
    Соединение = Новый HTTPСоединение("localhost", 11434, , , , 120);
    Запрос = Новый HTTPЗапрос("/api/generate");
    Запрос.Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");
    Запрос.УстановитьТелоИзСтроки(ТелоЗапроса, КодировкаТекста.UTF8);

    // 3. Отправляем и получаем ответ
    Попытка
        Ответ = Соединение.ВызватьHTTPМетод("POST", Запрос);
    Исключение
        Возврат "Ошибка подключения: " + ОписаниеОшибки();
    КонецПопытки;

    // 4. Разбираем JSON-ответ
    Если Ответ.КодСостояния = 200 Тогда
        ЧтениеJSON = Новый ЧтениеJSON;
        ЧтениеJSON.УстановитьСтроку(Ответ.ПолучитьТелоКакСтроку("UTF-8"));
        Результат = ПрочитатьJSON(ЧтениеJSON);
        Возврат Результат.response;
    Иначе
        Возврат "Ошибка Ollama. Код: " + Ответ.КодСостояния;
    КонецЕсли;

КонецФункции
```

### Как использовать в 1С

1. Откройте **Конфигуратор** вашей базы 1С.
2. Создайте **Общий модуль** (например, `РевьюКода`).
3. В свойствах модуля поставьте галочку **«Сервер»**.
4. Скопируйте туда функцию `ОтправитьКодНаРевью`.
5. Вызывайте её из любого места программы, передавая текст кода 1С.
